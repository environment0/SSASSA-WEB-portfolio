##  Project Overview

전자제품을 온라인에서 편리하게 조회하고 구매할 수 있도록 구현한 **웹 기반 쇼핑몰 프로젝트**입니다.
상품 목록 및 상세 조회, 검색, 장바구니, 주문 기능을 비롯하여 **KakaoPay 결제 및 환불 신청**, 문의 게시판과 관리자 기능을 구현했습니다.
실제 쇼핑몰 서비스를 고려하여 **사용자와 관리자 기능을 구분**하고, 상품부터 주문 및 결제까지의 전체적인 쇼핑몰 흐름을 구현하는 것을 목표로 했습니다.

##  Troubleshooting

### 1. 상품 정렬 기능 구현

상품 목록에서 가격 및 상품명을 기준으로 정렬할 수 있도록 정렬 조건을 처리했습니다.

### 2. 장바구니 데이터 관리

사용자가 선택한 상품과 수량을 관리하고 주문 단계에서 상품 금액을 계산하도록 구현했습니다.

### 3. KakaoPay 결제 연동

KakaoPay API를 연동하여 결제 요청부터 승인까지의 흐름을 구현하고 결제 성공 및 실패 상황을 처리했습니다.

### 4. 환불 처리

결제 이후 사용자가 환불을 신청할 수 있도록 환불 신청 및 상태 관리 기능을 구현했습니다.



##  프로젝트를 통해 경험한 내용

Spring Boot 기반의 웹 애플리케이션 개발 과정을 경험했습니다.

Spring Data JPA를 활용하여 상품, 회원, 주문, 결제 등의 데이터를 데이터베이스와 연동하고, Thymeleaf를 통해 서버에서 데이터를 전달하여 웹 페이지에 동적으로 표시하는 구조를 구현했습니다.

또한 **상품 → 장바구니 → 주문 → 결제**로 이어지는 쇼핑몰의 전체적인 서비스 흐름을 직접 구현하면서 각 기능 간의 데이터 연계와 처리 과정을 이해할 수 있었습니다.

KakaoPay API를 연동하여 외부 결제 시스템과 통신하고 결제 요청 및 승인 과정을 구현하면서 **외부 API 연동 경험**을 쌓았습니다.

CRUD 기능을 구현하는 과정에서는 사용자 문의 및 게시판 등의 데이터를 생성, 조회, 수정, 삭제하는 기능을 구현하며 Spring Boot와 JPA를 활용한 데이터 처리 방식을 경험했습니다.

마지막으로 Git과 GitHub를 활용하여 소스 코드를 관리하고 프로젝트 버전을 관리하면서 실제 개발 환경에서 필요한 **형상 관리와 협업의 기본적인 흐름**을 경험했습니다.
