# SSASSA 쇼핑몰 프로젝트

Spring Boot와 JSP를 기반으로 구현한 전자기기 쇼핑몰 웹 애플리케이션입니다.

 단순한 상품 CRUD 구현에 그치지 않고, **회원 → 상품 조회 → 장바구니 → 결제 → 구매 내역 → 환불 요청 → 관리자 처리**까지 실제 쇼핑몰에서 이루어지는 전체 흐름을 구현하는 것을 목표로 개발했습니다.
카카오페이 API를 이용한 실제 결제 흐름과 Synology NAS WebDAV를 활용한 이미지 관리, 상품 이미지 캐싱, 관리자 페이지 등 서버 중심의 기능 구현에 중점을 두었습니다.

## 개발 목적

 웹 개발 과정에서 각각의 기능을 개별적으로 구현하는 것보다 실제 서비스처럼 기능들이 서로 연결되는 구조를 경험하는 것을 목표로 했습니다.
사용자가 상품을 검색하고 옵션을 선택한 뒤 장바구니 또는 바로 구매를 통해 결제를 진행할 수 있도록 구성했으며, 결제 이후에는 마이페이지에서 구매 내역과 환불 상태를 확인할 수 있도록 구현했습니다.
관리자는 별도의 관리 화면에서 회원, 상품, 카테고리, 문의, 결제 및 환불 요청을 관리할 수 있도록 구성했습니다.
특히 외부 서비스와의 연동 경험을 위해 **카카오페이 API, Gmail SMTP, Synology NAS WebDAV**를 프로젝트에 적용했습니다.

# 주요 구현 기능

## 1. 상품 조회 및 검색

 카테고리를 기준으로 상품을 구분하여 조회할 수 있으며, 사용자가 원하는 상품을 쉽게 찾을 수 있도록 검색 기능을 구현했습니다.
상품 하나에 여러 옵션이 존재할 수 있도록 `ProductVariant` 구조를 사용하여 옵션별 가격과 상품 정보를 관리합니다.
주요 기능은 다음과 같습니다.

* 카테고리별 상품 조회
* 상품명 기반 검색
* 상품 상세 정보 조회
* 상품 옵션 및 옵션별 가격 관리
* 상품 대표 이미지 및 상세 이미지 출력
* 장바구니 수량 변경
* 단일 상품 및 복수 상품 구매

---

## 2. 카카오페이 결제

 카카오페이 API를 연동하여 상품 구매 과정을 구현했습니다.
사용자는 상품 상세 페이지에서 바로 구매하거나 장바구니에 담긴 여러 상품을 한 번에 결제할 수 있습니다.
결제는 다음과 같은 흐름으로 처리됩니다.

```text
상품 선택
   ↓
결제 요청
   ↓
카카오페이 결제 준비
   ↓
카카오페이 결제 페이지
   ↓
pg_token 전달
   ↓
결제 승인
   ↓
결제 정보 DB 저장
   ↓
구매 내역 확인
```

결제 과정에서는 단순히 API 호출 결과만 출력하는 것이 아니라 `Payment` 엔티티를 이용하여 결제 결과와 사용자 구매 정보를 데이터베이스에 저장하도록 구성했습니다.

### 구현 기능

* 단일 상품 바로 결제
* 장바구니 복수 상품 결제
* 카카오페이 결제 준비 요청
* 결제 승인 처리
* 결제 성공 및 실패 처리
* 사용자별 결제 내역 저장
* 사용자 환불 요청
* 관리자 환불 승인
* 카카오페이 결제 취소 API 연동

## 3. 회원 시스템

 회원가입부터 로그인, 개인정보 관리, 계정 탈퇴까지 일반적인 쇼핑몰 회원 기능을 구현했습니다.
비밀번호는 평문으로 저장하지 않고 Spring Security Crypto를 이용해 암호화하여 저장하도록 구성했습니다.

### 주요 기능

* 회원가입
* 로그인 / 로그아웃
* 세션 기반 로그인 상태 관리
* 로그인 유지 기능
* 회원정보 조회 및 수정
* 프로필 이미지 등록
* 회원 탈퇴
* 아이디 찾기
* 비밀번호 재설정
* 이메일을 통한 임시 비밀번호 발송

 로그인한 사용자가 자신의 정보를 직접 확인하고 관리할 수 있는 공간입니다.
회원정보뿐만 아니라 쇼핑몰 이용 과정에서 발생한 결제와 문의 내역도 함께 확인할 수 있도록 구성했습니다.

### 제공 기능

* 회원정보 조회

* 결제 내역 조회
* 환불 요청
* 문의 내역 확인
* 회원 탈퇴

 상품을 구매한 사용자가 해당 상품에 대한 리뷰를 작성할 수 있도록 구현했습니다.
다른 사용자가 도움이 된 리뷰를 표시할 수 있도록 추천 기능도 추가했습니다.

# 이미지 캐싱

 상품 목록에서 이미지 정보를 반복적으로 조회하면서 발생할 수 있는 불필요한 DB 접근을 줄이기 위해 이미지 캐시를 구현했습니다.
`ProductImgCache`는 애플리케이션 시작 시 필요한 상품 이미지 정보를 메모리에 저장하고 이후 상품 목록을 출력할 때 캐시된 데이터를 활용합니다.

```text
Application Start
       ↓
상품 이미지 정보 조회
       ↓
ProductImgCache 저장
       ↓
상품 목록 요청
       ↓
Cache에서 이미지 URL 조회
```

 상품 이미지가 등록, 수정 또는 삭제되는 경우에는 캐시의 데이터도 함께 변경되도록 구성했습니다.
카테고리 데이터는 `CategoriesCache`를 통해 관리합니다.

# NAS WebDAV 파일 관리

 이미지 파일을 애플리케이션 서버 내부에 직접 저장하지 않고 **Synology NAS의 WebDAV 서버와 연동하여 별도로 관리**하도록 구현했습니다.
이 구조를 통해 데이터베이스에는 실제 이미지 바이너리를 저장하지 않고 이미지 위치와 관련된 정보만 관리합니다.

```text
사용자 파일 업로드
        ↓
파일 크기 / 형식 검증
        ↓
파일명 변환
        ↓
WebDAV 요청
        ↓
Synology NAS 저장
        ↓
DB에 파일 정보 저장
```

### 적용 대상

* 상품 대표 이미지
* 상품 상세 이미지
* 상품 옵션 이미지
* 사용자 프로필 이미지
* 문의 첨부파일

### 파일 처리

* 최대 파일 크기 제한
* 파일 확장자 및 타입 검증
* 중복 파일명 방지

# 프로젝트를 통해 경험한 내용

* 카카오페이 외부 API 연동
* 결제 승인 및 환불 처리
* MySQL 기반 데이터 관리
* 세션 및 쿠키를 활용한 로그인 상태 관리
